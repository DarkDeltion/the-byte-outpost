## Productfoto's

De foto's zijn per productmodel geselecteerd. De opgegeven telefoonkleur komt overeen met de JSON. Waar de productnaam alleen een familie noemt (bijvoorbeeld ThinkPad, IdeaPad of Pavilion), is een representatief model uit die familie gebruikt. RAM en opslag kunnen binnen dezelfde behuizing verschillen. De bronpagina identificeert het afgebeelde model; de productgegevens zijn niet gewijzigd.

Productfoto's blijven eigendom van de betreffende merken en bronhouders.
