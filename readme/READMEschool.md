# project gegevens

De naam van het project is "The-Byte-Outpost". 

Deze website kan je best vergelijken met andere electronica winkels, die bijvoorbeeld gespecializeerd zijn Computer onderdelen naar printers en andere electronica.
je kan dit vergelijken met megekko, azerty of alternate.

De reden waarom ik voor dit project heb gekozen is omdat ik graag een nieuwe framework wou uitproberen en een nieuwe soort website wil maken want ik heb nooit een webshop gemaakt.

de randvoorwaarden die aanwezig zijn bij de website zijn:

- **AVG en privacy:** Met gebruik van de webshop wordt alle data gehasht en niet opgeslagen. Met de gegevens moet ik betalingen en pakketen verzenden. Alles wordt op een lokale database gezet en niet openbaar gezet. De gebruiker kan de gegevens verwijderen door een webpage.

- **Copyright:** De bron van de foto's worden allemaal vermeld en worden gecrediteerd. 

- **Licenties:** De licenties van next.js en tailwind zijn open-source en worden gebruikt volgens een mit-licentie.

- **Wettelijke impact:** De prijzen van de producten zijn inclusief btw. de verzendkosten worden duidelijk vermeld. 

- **maatschappelijke impact:** De website heeft geen maatschappelijke impact, maar is een online webshop.
