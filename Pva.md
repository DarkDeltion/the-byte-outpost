# Plan van Aanpak

## 1. Huidige situatie
Wat is er nu en wat is het probleem?

- op dit moment is er no ggeen website waarop klanten de producten kunnen bekijken en bestellen van the-byte-outpost. hierbij wil ik een plek maken waarbij je alle producten die wij verkopen kan zien en kan kopen.

## 2. Gewenste situatie
Wat moet er aan het einde van het project zijn?

- in het einde moet er een voledig webshop actief werkend zijn. bijvoorbeeld dat je producten in de winkelwagen kan doen, dat je producten kan inzien, aankopen kan maken, adress kan in vullen en dat je een mail krijgt over je aankoop.

## 3. Doel en resultaat
Wat levert mijn website/app op?

- ik wil graag iets opleveren dat het makkelijk is voor klanten en andere mensen een laptop of mobiel kan halen zonder problemen met het door zoeken van meerdere knoppen of andere dingen.

## 4. Doelgroep
Voor wie maak ik het?

- ik maak het voor jongeren en volwasennen die graag een laptop of telefoon moet halen voor persoonlijk gebruik of zelfs een werklaptop / telefoon kan halen.

## 5. Kanalen en zoekmachines
Hoe kan mijn doelgroep het product vinden?

- Product kan je vaak vinden via Advertenties online of bij het zoeken van de website naam op google en andere social media bijvoorbeeld.

## 6. Technieken
Welke programmeertalen, frameworks en andere technieken gebruik ik?
Waarom heb ik hiervoor gekozen?

- ik ben vanplan om Typescript, CSS en HTML te gaan gebruiken voor de talen. framework wordt Next.js react framework en voor css ga ik Tailwind nog bij gebruiken. ook ga ik Git gebruiken voor github.

## 7. Devices
Op welke apparaten moet het werken en hoe houd ik daar rekening mee?

- de website wordt aan verschilende formaten gewerkt zodat je het goed op Telefoon, tablet en Laptop kan zien. ook test ik hoe snel de website is en hoe optimized 

## 8. Testplan
Hoe ga ik controleren of alles goed werkt?

- ik test alles via de plugin lighthouse hierbij kan je de optimalizatie van de website zien maar ook hoe snel die werkt. of die makkelijk kan vinden met metadata en andere dingen die zorgen dat een website prima runt.

## 9. Planning
Wat ga ik wanneer doen?

- Ik ga alles via een kanbanboard plannen en daar via een agenda gezet. hierbij hou ik wat ik heb gedaan en dat ik.
